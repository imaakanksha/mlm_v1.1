## About This Submission

**Hackathon**: Republic Day 24-Hour Flash Sprint (January 26, 2026)

**Project**: Multilingual Mandi - Breaking language barriers in Indian local markets

### Key Features Implemented
- ✅ Real-time translation (10 Indian languages)
- ✅ AI-powered price discovery (Gemini API)
- ✅ Negotiation assistance
- ✅ Voice input support (Web Speech API)
- ✅ Mobile-first responsive UI

### Tech Stack
- **Backend**: Python FastAPI
- **AI**: Google Gemini API (Free Tier)
- **Frontend**: Vanilla HTML/CSS/JS
- **Speech**: Web Speech API

### Social Impact (Viksit Bharat)
- Economic inclusion for vendors with limited language skills
- Fair trade through AI-powered transparent pricing
- Digital empowerment of local market participants
- Regional integration across linguistic barriers
